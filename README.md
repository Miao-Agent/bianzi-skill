## 为什么用 鞭子

信任/压力/编排/说服/路由/辩证六模式 + P0 极简门控(ponytail) + R18 强化态。

## 核心能力

1. **架构总览**
2. **常驻规则**
3. **六模式协同工作流(v1.5核心)**
4. **愤怒/错误强化态（v1.3.0新增）**
5. **路由决策树**
6. **六模式速查**
7. **祛幻集成(全时在线)**
8. **模式切换日志**
